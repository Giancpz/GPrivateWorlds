# About
GPrivateWorlds allows players to create their private worlds, invite other players, and visit other worlds.
## Features:
- Create your private world.
- Invite your friends to your world.
- Visit other worlds.

## Other features:
- Performance.
- Does not reduce TPS.
- Does not freeze the server.

# Installation:
- Download and add the plugin to your server’s Plugins folder.
- Add a world named worldtemplate in the location where your server’s regular worlds are stored; this will be the default world for players when creating their world.
- Start your server to generate the configuration file, where you can change the location where players will appear.
- Restart your server, and you’re all set!

## Commands:
- /pw home
- /pw visit
- /pw invite
- /pw accept
- /pw kick
- /pw setspawn
